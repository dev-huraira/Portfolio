Case Study

PixAura

A modern, portfolio-ready image tools web app with 11 browser-based utilities, AI background removal, and a glassmorphism UI � built with React, TypeScript, and Vite.

Role Full-Stack Developer
Timeline 1.5 Months
Stack React 18 � TypeScript � Vite � Tailwind � shadcn/ui
Status ? Live

The Challenge

Image editing workflows typically force users into heavy desktop apps or questionable online tools that upload private photos to unknown servers. I wanted to build a privacy-friendly, browser-based image processing suite that handles common tasks entirely on the client side � fast, free, and secure.

The goal: a single app that covers the full image workflow � compress, resize, convert, crop, rotate, watermark, extract metadata, and even handle PDF conversions � all without ever sending files to a server (except for AI features).

The Approach

  • Built with React 18 + TypeScript + Vite for a fast, type-safe developer experience with instant HMR
  • Designed a modern glassmorphism UI using Tailwind CSS and shadcn/ui components for a consistent, premium look
  • Implemented all core image operations client-side using the Canvas API and Web Workers � no server uploads for compression, resizing, cropping, or format conversion
  • Integrated Replicate API (U�-Net segmentation) for AI-powered background removal with a server-side middleware route to protect API tokens
  • Built a demo mode fallback that serves static mock outputs for portfolio deployments without API billing
  • Used pdf-lib and pdfjs-dist for client-side PDF-to-image and image-to-PDF conversions
  • Deployed on Vercel with SPA route rewrites for clean URL handling

Complete Toolset � 11 Tools

  • Compress Image � Reduce file size with adjustable quality while preserving visual fidelity
  • Resize Image � Scale images to exact dimensions or percentage with aspect ratio lock
  • Convert Format � Switch between PNG, JPEG, WebP, and other formats instantly
  • Crop Image � Interactive crop with preset ratios (1:1, 16:9, 4:3) and free-form selection
  • Rotate & Flip � 90� rotations and horizontal/vertical flipping
  • Add Watermark � Overlay text or image watermarks with position, opacity, and size controls
  • Background Remover � AI-powered segmentation with interactive before/after comparison slider
  • Image to PDF � Combine multiple images into a single PDF with page ordering
  • PDF to Images � Extract individual pages from PDFs as high-quality images
  • Bulk Processing � Batch compress, resize, or convert multiple files simultaneously
  • Metadata Viewer � Read EXIF data including camera info, GPS coordinates, and timestamps

Technical Highlights

The AI background removal was the most complex feature. The live mode sends images to U�-Net segmentation via the Replicate API through a secure server-side route � API tokens never touch the client. For portfolio deployments, I built a demo mode that returns a pre-processed transparent PNG, allowing the full UI flow to work without incurring API costs.

For client-side processing, I leveraged the Canvas API extensively � resizing uses Lanczos resampling for quality, compression adjusts JPEG quality parameter dynamically, and format conversion creates new Blob objects from canvas data. All operations are non-blocking using async patterns to keep the UI responsive even on large files.

The metadata viewer uses the exifr library to parse EXIF, IPTC, and XMP data directly in the browser, displaying camera model, lens info, exposure settings, GPS coordinates, and more.

Results

  • 11 fully functional image tools running entirely in the browser
  • Privacy-first architecture � zero server uploads for core tools
  • AI background removal with interactive before/after comparison
  • Clean, responsive glassmorphism UI that works across all devices
  • Portfolio-safe demo mode for billing-free deployments
  • Modular component architecture with reusable processing utilities
